# 交通費申請チェッカー（AI判定）

様式や表記がバラバラな交通費申請を、Claude APIで自動判定するツールです。

## 背景
RPA（WinActor）の導入支援を4年間担当する中で、経費精算のような申請業務は
「金額の表記ゆれ」や「理由の妥当性判断」が必要なため、RPA単体では自動化しきれない
場面を多く見てきました。

このツールは、判断が必要な部分を生成AIに任せ、確実に処理すべき部分はルールやRPAに
任せる、という役割分担を検証するために作成しました。

## できること
- 金額の表記ゆれ（「1,240」「￥290」「５８０円」）を整数に正規化
- 理由が業務目的として妥当かを判定（「私用」「なんとなく」を検出）
- 研修は上限5,000円、それ以外は3,000円で上限チェック
- 判定結果を OK / 要確認 / NG で出力し、CSVに保存

## 精度と改善
正解データ8件で、プロンプトの改善前後を各3回比較しました。

| | 改善前 | 改善後 |
|---|---|---|
| 平均一致率 | 88% | 100% |
| 見逃し（NGをOKにした件数） | 0件 | 0件 |
| 判定がぶれた申請 | 2件 | 0件 |
| 1件あたりの料金 | 約0.24円 | 約0.26円 |

改善の内容：
1. 判定ルールに優先順位をつけた
2. 「迷った場合は要確認」と明記し、見逃しを防ぐ側に倒した
3. 判定がぶれた「出張」「研修」などの判定例を追加した（few-shot）

判定がぶれた原因は、AIではなく**業務ルールが明文化されていない部分**にありました。

※ 調整に使ったデータでの結果のため、別の評価用データでの検証を予定しています。

## 設計で工夫した点
- ルールで確実に判定できる処理と、AIの判断が必要な処理を分ける設計を想定
- API失敗とJSONの崩れの両方に例外処理を実装
- APIキーは `.env` で管理し、リポジトリには含めない

## 使い方
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
# .env に ANTHROPIC_API_KEY=... を記載
python ai_checker.py
```
